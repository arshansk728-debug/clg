🚀 How to Run the Full Project:

  1. Install MongoDB: Download from mongodb.com
  2. Install Dependencies: Run npm install in the backend folder
  3. Set up Environment: Copy env.example to .env and configure
  4. Start Server: Run node server.js in the backend folder
  5. Open: http://localhost:3000

🐳 Or Use Docker (Easiest):

  1. Install Docker Desktop for Windows
  2. Run: docker-compose up -d
  3. Access: http://localhost:3000
