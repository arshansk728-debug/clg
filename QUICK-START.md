# 🚀 Quick Start Guide

## **Choose Your Setup Method:**

### **Method 1: Test Mode (Easiest - No Database Required)**
```bash
# Double-click this file:
start-project.bat
```
- ✅ Works immediately
- ✅ No database setup needed
- ✅ Perfect for testing the interface
- ⚠️ Limited functionality (mock responses only)

### **Method 2: Full Project (Complete Functionality)**
```bash
# Double-click this file:
start-full-project.bat
```
- ✅ Full database integration
- ✅ AI-powered responses
- ✅ Complete admin panel
- ⚠️ Requires MongoDB setup

### **Method 3: Docker (Recommended for Production)**
```bash
# Double-click this file:
start-docker.bat
```
- ✅ Everything included
- ✅ No manual setup required
- ✅ Production-ready
- ⚠️ Requires Docker Desktop

## **Troubleshooting:**

### **If Test Mode doesn't work:**
1. Make sure Node.js is installed
2. Run: `npm install` in the backend folder
3. Try: `node test-server.js`

### **If Full Project doesn't work:**
1. Install MongoDB locally or use MongoDB Atlas
2. Update `.env` file with your MongoDB connection
3. Make sure all dependencies are installed

### **If Docker doesn't work:**
1. Install Docker Desktop
2. Make sure Docker is running
3. Check if ports 3000 and 27017 are available
